# Demo: managed-settings.json

**Sesi 4.1** · 8 menit · branch `lab/L4.1-solution` · berkas `managed-settings.json`

## Dari slide

Teks di bawah ini sama persis dengan slide demo.

| | |
| --- | --- |
| sandbox.enabled | true |
| failIfUnavailable | true → Claude Code tidak mau jalan tanpa sandbox |
| allowUnsandboxedCommands | false → tidak ada jalan pintas keluar sandbox |
| allowManagedDomainsOnly | true → hanya domain dari daftar organisasi |
| credentials | ~/.ssh, ~/.aws: deny untuk perintah sandbox |
| Distribusi | MDM ke berkas sistem, atau server-managed dari Claude.ai |

> Kebijakan agen ditegakkan admin, bukan dititipkan ke developer

### Catatan pembicara

- **Buka.** Tampilkan berkas managed-settings.json.
- **Inti.** sandbox.enabled true, sandbox.failIfUnavailable true, sandbox.allowUnsandboxedCommands false, sandbox.network.allowManagedDomainsOnly true dengan allowedDomains organisasi, sandbox.credentials menolak ~/.ssh dan ~/.aws. Lokasi: /etc/claude-code/ di Linux, /Library/Application Support/ClaudeCode/ di macOS, C:\Program Files\ClaudeCode\ di Windows (jalur lama C:\ProgramData tidak lagi dibaca), atau server-managed settings dari konsol admin Claude.ai.
- **Nuansa.** Sandbox tidak berjalan di Windows native; arahkan pengguna Windows ke WSL2 atau kontainer.

## Skrip demo

Branch `lab/L4.1-solution`, laptop uji Linux/macOS dengan hak admin.

1. Buka `managed-settings.json`. Sorot baris sesuai tabel slide: `sandbox.enabled`, `failIfUnavailable`,
   `allowUnsandboxedCommands`, `network.allowManagedDomainsOnly` + `allowedDomains`,
   `credentials.files` (deny `~/.ssh`, `~/.aws`), dan `disableBypassPermissionsMode`.
2. Pasang (Linux): `sudo mkdir -p /etc/claude-code && sudo cp managed-settings.json /etc/claude-code/`.
   macOS: `/Library/Application Support/ClaudeCode/`. Windows: `C:\Program Files\ClaudeCode\` (jalur lama `C:\ProgramData\ClaudeCode\` tidak lagi dibaca).
3. Ubah `.claude/settings.json` proyek menjadi `"sandbox": {"enabled": false}`, mulai ulang Claude,
   jalankan `/sandbox` dan `/permissions`: sandbox tetap aktif, aturan bersumber *Managed*.
4. Tunjukkan opsi distribusi: MDM ke berkas sistem, atau server-managed settings dari konsol admin Claude.ai.
5. Hapus berkas uji dan kembalikan `.claude/settings.json`.

## Rencana cadangan

- Tidak ada hak admin di laptop demo: tampilkan berkas dan `docs/hasil/L4.1-pengecualian.md`
  (hasil uji yang diharapkan).
- Peserta Windows: tegaskan sandbox butuh WSL2; dengan `failIfUnavailable: true` Claude Code tidak mau
  berjalan tanpa sandbox.
