### Catatan pembicara

- **Buka.** Tampilkan agent/triage_agent.py, ±130 baris Python (branch lab/L3.1-solution).
- **Inti.** ClaudeAgentOptions dengan allowed_tools terbatas (Read, Grep, Edit, Bash untuk pytest dan gh). Hook PreToolUse menolak path .env dan perintah di luar allowlist. System prompt: satu alert per jalan, tulis test negatif, buka PR draft, jangan merge. Jalankan pada satu alert dan tunjukkan log hook.
- **Persiapan.** pip install claude-agent-sdk (Python 3.10+), Claude Code terpasang, API key di variabel lingkungan, gh sudah login dengan token yang tidak punya hak merge.

## Skrip demo

Branch `lab/L3.1-solution`, `pip install -r requirements-dev.txt`, `ANTHROPIC_API_KEY` di environment,
`gh` login dengan token agen (fine-grained PAT tanpa hak merge), label `ai-generated` sudah dibuat.

1. Buka `agent/triage_agent.py` (±130 baris). Sorot berurutan sesuai tabel slide:
   `tools` dan `allowed_tools`, `guard` (PreToolUse: path sensitif, allowlist Bash, rangkaian perintah),
   `record` (PostToolUse ke `logs/agent-audit.jsonl`), dan `SYSTEM_PROMPT` (satu alert, test negatif,
   PR draft, jangan merge).
2. Uji hook tanpa API: `python -m pytest -q tests/test_triage_agent.py`.
3. Jalankan agen pada satu alert:

   ```bash
   python agent/triage_agent.py --alert docs/alert-contoh.json
   ```

4. Tunjukkan bukti: `tail logs/agent-audit.jsonl`, `gh pr list --draft`, `gh pr diff <nomor>`, check CI di PR.
5. Uji kanari: `git switch pr/L3.1-komentar-kanari`, jalankan lagi, `grep '"deny"' logs/agent-audit.jsonl`.

## Rencana cadangan

- API tidak tersedia: jalankan test hook (langkah 2) dan tunjukkan PR draft + log yang direkam saat persiapan
  (`docs/hasil/L3.1-pr-contoh.md` sebagai hasil yang diharapkan).
- Agen berputar lama: turunkan `max_turns` atau hentikan dengan Ctrl+C; jelaskan bahwa `max_budget_usd`
  menahan biaya.
