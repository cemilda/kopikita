## Dari slide

Teks di bawah ini sama persis dengan slide demo.

1. /security-review — satu pass cepat pada branch saat ini.
2. /plugin install claude-security@claude-plugins-official
3. /claude-security → Scan codebase → pilih folder api/

5. Unggah .sarif dengan github/codeql-action/upload-sarif.
6. Tab Security: filter tool → Claude berdampingan dengan CodeQL.

### Catatan pembicara

- **Buka.** Tunjukkan alur lengkap di layar, dari terminal sampai tab Security GitHub.
- **Inti.** Jalankan /security-review pada branch. Lalu /claude-security scan pada folder api/. Buka CLAUDE-SECURITY-RESULTS.md. Unggah berkas .sarif ke code scanning dengan action upload-sarif. Tunjukkan temuan Claude muncul berdampingan dengan alert CodeQL dan bisa difilter per tool.
- **Nuansa.** Folder hasil scan punya .gitignore sendiri agar tidak ikut ter-commit. Untuk jejak audit, hapus .gitignore itu dan commit foldernya.

## Skrip demo

Branch `lab/L2.3-start` (sebelum remediasi) di laptop; fork dengan default branch yang sama.

1. Di sesi Claude: `/security-review` → satu pass cepat atas perubahan pada branch saat ini.
2. `/plugin install claude-security@claude-plugins-official`, lalu `/claude-security` → **Scan codebase**
   → pilih folder `api/`.
3. Buka `CLAUDE-SECURITY-RESULTS.md`: tunjukkan dampak, skenario serangan, dan severity per temuan.
4. Tunjukkan bahwa folder hasil scan punya `.gitignore` sendiri. Untuk jejak audit, hapus `.gitignore`
   itu, commit berkas `.sarif`, push.
5. Actions → **Unggah SARIF Claude Security** (`.github/workflows/upload-claude-sarif.yml` dari
   `lab/L2.3-solution`) → **Run workflow** dengan path berkas `.sarif`.
   Workflow memakai `github/codeql-action/upload-sarif` kategori `claude-security`.
6. Security → Code scanning → filter **Tool** → temuan Claude berdampingan dengan CodeQL.

## Rencana cadangan

- Scan memakan waktu lama: siapkan hasil scan yang dijalankan sebelum kelas (berkas `.md` dan `.sarif`).
- Workflow unggah belum ada di branch demo: salin dari `lab/L2.3-solution`
  (`git restore --source lab/L2.3-solution -- .github/workflows/upload-claude-sarif.yml`).
- Nama folder/berkas hasil plugin bisa berubah antarversi; cek README plugin sebelum kelas.
