# Demo: workflow review keamanan PR

**Sesi 2.4** · 8 menit · branch `lab/L2.4-solution` · berkas `.github/workflows/security-review.yml`

## Dari slide

Teks di bawah ini sama persis dengan slide demo.

| | |
| --- | --- |
| on | pull_request: opened, synchronize |
| permissions | contents: read · pull-requests: write |
| steps | actions/checkout (fetch-depth: 2) · claude-code-security-review |
| with | comment-pr: true · claude-api-key: secret repo |
| Tanya jawab | anthropics/claude-code-action@v1 → mention @claude |
| Batasan | Hanya PR tepercaya · belum tahan prompt injection |

### Catatan pembicara

- **Buka.** Tampilkan berkas .github/workflows/security-review.yml.
- **Inti.** Pemicu pull_request. Blok permissions minimal: contents read, pull-requests write. Checkout dengan fetch-depth 2. Langkah anthropics/claude-code-security-review dengan comment-pr true dan secret API key. Untuk tanya-jawab @claude di PR, pakai anthropics/claude-code-action@v1.
- **Jebakan.** Jangan memakai pull_request_target untuk PR dari fork tanpa sandboxing; itu memberi akses secret ke kode yang tidak tepercaya.
- **Persiapan.** Tambahkan secret repo berisi API key Claude. Pemakaian menghabiskan token API dan menit GitHub Actions.

## Skrip demo

Fork instruktur, secret `ANTHROPIC_API_KEY` sudah ada, PR uji sudah dibuka 10 menit sebelum demo
(`pr/L2.4-pr-xss` → `lab/L2.4-solution`) agar review sudah selesai.

1. Buka `.github/workflows/security-review.yml` di `lab/L2.4-solution`. Sorot baris per baris sesuai
   tabel slide: `on`, `permissions`, `actions/checkout` dengan `fetch-depth: 2`, action review dipin SHA,
   `comment-pr: true`, `claude-api-key`.
2. Buka PR uji → tab **Files changed**: komentar inline Claude di `api/greeting.py`.
3. Tab **Checks**: bandingkan dengan alert CodeQL `py/reflective-xss`.
4. Push perbaikan (`escape(name)`) ke branch PR; tunjukkan workflow berjalan lagi (`synchronize`).
5. Jelaskan batasannya: hanya PR tepercaya, jangan `pull_request_target` untuk fork, belum tahan prompt injection.
   Untuk tanya-jawab `@claude`, workflow terpisah dengan `anthropics/claude-code-action@v1`.

## Rencana cadangan

- Kuota API habis atau review lambat: tampilkan PR dari kelas sebelumnya, atau tangkapan layar komentar.
- Tunjukkan `docs/hasil/L2.4-perbandingan.md` sebagai hasil yang diharapkan.
