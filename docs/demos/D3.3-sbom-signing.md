# Demo: SBOM dan tanda tangan image

**Sesi 3.3** · 6 menit · branch `lab/L3.3b-solution` · berkas `.github/workflows/release.yml`

## Dari slide

Teks di bawah ini sama persis dengan slide demo.

| | |
| --- | --- |
| SBOM | trivy image --format cyclonedx -o sbom.json <image> |
| Tandatangani | cosign sign <image@digest>  (keyless, OIDC workflow) |
| Provenance | actions/attest-build-provenance pada artefak |
| Izin | id-token: write hanya pada job penanda tangan |
| Verifikasi | cosign verify --certificate-identity <workflow> --certificate-oidc-issuer <issuer> |

### Catatan pembicara

- **Buka.** Tambahkan tiga langkah di akhir workflow build image.
- **Inti.** Buat SBOM CycloneDX dengan Trivy, tandatangani image dengan cosign memakai identitas OIDC workflow (keyless), dan buat attestation provenance dengan GitHub artifact attestations. Di sisi deploy, verifikasi tanda tangan dengan identitas workflow yang persis.
- **Nuansa.** Job yang menandatangani butuh izin id-token: write; beri hanya pada job itu, bukan seluruh workflow.

## Skrip demo

Fork instruktur dengan default branch `lab/L3.3b-solution`; satu run `Release image` sudah sukses.

1. Buka `.github/workflows/release.yml`. Sorot tiga langkah terakhir sesuai tabel slide:
   SBOM Trivy CycloneDX (`sbom.json`), `cosign sign` keyless, `actions/attest-build-provenance`.
2. Sorot izin: `id-token: write` **hanya** di job `build-sign`; tingkat workflow `contents: read`.
3. Unduh artefak `sbom`, tunjukkan komponen (`jq '.components | length' sbom.json`).
4. Verifikasi:

   ```bash
   GITHUB_REPOSITORY=<owner>/kopikita-vuln IMAGE_REF=refs/heads/lab/L3.3b-solution \
     bash scripts/verify-image.sh ghcr.io/<owner>/kopikita-vuln@sha256:<digest>
   ```

5. Ulangi dengan `IMAGE_REF=refs/heads/main` → gagal. Jelaskan bahaya `--certificate-identity-regexp '.*'`.

## Rencana cadangan

- Rekor/Fulcio lambat: tampilkan log run yang sukses dan tab Attestations.
- Tanpa cosign lokal: `gh attestation verify oci://ghcr.io/<owner>/kopikita-vuln@sha256:<digest> --repo <owner>/kopikita-vuln`.
