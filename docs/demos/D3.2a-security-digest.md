### Catatan pembicara

- **Buka.** Tampilkan workflow security-digest.yml.
- **Inti.** Pemicu schedule mingguan. Langkah gh api mengambil alert code scanning dan Dependabot 7 hari terakhir ke berkas JSON. anthropics/claude-code-action@v1 dengan prompt: ringkas per severity dan tulis digest.md. claude_args membatasi --max-turns 8 dan --allowedTools "Read,Write". Langkah gh terakhir membuat issue dari digest.md, jadi Claude tidak memegang tool tulis GitHub. permissions: contents read, issues write, security-events read. Semua action dipin ke SHA.
- **Nuansa.** Agent mode (prompt) berbeda dari tag mode (mention @claude). Untuk jadwal, pakai prompt.

## Skrip demo

Fork instruktur dengan default branch `lab/L3.2-solution`, secret `ANTHROPIC_API_KEY`.

1. Buka `.github/workflows/security-digest.yml`. Sorot sesuai tabel slide: `cron: "7 0 * * 1"` (UTC) =
   Senin 07.07 WIB, `permissions`, action dipin SHA, `prompt`, `claude_args`.
2. Jelaskan tiga langkah "agen menyusun, pipeline bertindak": `gh api` → JSON; Claude (`Read,Write`) →
   `digest.md`; `gh issue create`. Claude tidak memegang tool tulis GitHub.
3. ```bash
   gh workflow run security-digest.yml --ref lab/L3.2-solution
   gh run watch
   gh issue list --search "Security digest"
   ```
4. Buka issue: cocokkan satu angka dengan log langkah pertama (`code scanning: N · dependabot: M`).
5. Bandingkan agent mode (`prompt`, untuk jadwal) dengan tag mode (mention `@claude` di PR/issue).

## Rencana cadangan

- Run lambat: tampilkan issue digest dari run sebelumnya.
- Tidak ada alert dalam 7 hari: jelaskan bahwa digest berisi tabel kosong; ubah `7 days ago` menjadi
  `30 days ago` di branch demo bila perlu menunjukkan isi.
