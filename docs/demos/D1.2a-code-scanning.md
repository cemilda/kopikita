# Demo: mengaktifkan code scanning

**Sesi 1.2** · 8 menit · branch `lab/L1.2-solution` · berkas `.github/workflows/codeql.yml`

## Dari slide

Teks di bawah ini sama persis dengan slide demo.

1. Settings → Advanced Security → CodeQL analysis → Set up → Default.
2. Atau Advanced: commit .github/workflows/codeql.yml dengan queries: security-extended.
3. Tunggu workflow selesai di tab Actions.
4. Tab Security → Code scanning: buka alert SQL injection, baca jalur data.
5. Dismiss dengan alasan bila false positive; jangan dismiss tanpa alasan.

### Catatan pembicara

- **Buka.** Tampilkan layar Anda. Peserta menonton dulu, lalu mengulang di lab.
- **Inti.** Tunjukkan dua jalan: default setup (beberapa klik) dan advanced setup (berkas workflow codeql.yml). Tunjukkan hasil di tab Security, buka satu alert, lihat jalur source ke sink.
- **Persiapan.** Jalankan analisis sehari sebelumnya; analisis pertama bisa memakan beberapa menit.

## Skrip demo

Repo demo: fork instruktur, default branch `lab/L1.2-solution` (analisis sudah dijalankan sehari sebelumnya).

1. **Default setup**: Settings → Advanced Security → Code scanning → CodeQL analysis → **Set up → Default**.
   Tunjukkan dialog bahasa dan *query suite* (Default / Extended), lalu **batalkan**: kita memakai advanced.
2. **Advanced**: buka `.github/workflows/codeql.yml` di branch `lab/L1.2-solution`. Sorot `queries: security-extended`,
   matriks `python` + `javascript-typescript`, dan `security-events: write` yang hanya ada di job.
3. Tab **Actions → CodeQL**: tunjukkan run yang sudah selesai (dua job, satu per bahasa).
4. Tab **Security → Code scanning**: buka alert `py/sql-injection` di `api/app.py` → **Show paths**.
   Telusuri langkah demi langkah: `request.get_json()` → `username` → penggabungan string → `cur.execute(query)`.
5. Buka alert `ORDER BY {sort}` bila muncul → **Dismiss alert → False positive**, komentar:
   "nilai divalidasi allowlist kopikita.safe_sql". Tunjukkan bahwa alasan tersimpan di histori alert.

## Rencana cadangan

- Analisis belum selesai atau Actions antre: tunjukkan tangkapan layar alert dan jalur data yang direkam
  saat persiapan, lalu buka `docs/hasil/L1.2-triase.md` di `lab/L1.2-solution` sebagai daftar alert yang diharapkan.
- Tanpa internet: tampilkan `codeql.yml` di editor dan jelaskan alurnya dari berkas.
