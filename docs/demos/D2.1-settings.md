# Demo: settings.json yang aman

**Sesi 2.1** · 10 menit · branch `demo/settings` · berkas `.claude/settings.json`

## Dari slide

Teks di bawah ini sama persis dengan slide demo.

| | |
| --- | --- |
| permissions.deny | Read(./.env*) · Read(~/.ssh/**) · Read(~/.aws/**) |
| permissions.ask | Bash(git push *) · Bash(docker *) |
| permissions.allow | Bash(pytest *) · Bash(npm run test *) |
| sandbox | enabled · domain: github.com, pypi.org, files.pythonhosted.org |
| hooks.PreToolUse | Skrip yang mencatat setiap perintah Bash ke log audit |
| Periksa | /permissions · /sandbox |

> Aturan proyek di git, preferensi pribadi di settings.local.json

### Catatan pembicara

- **Buka.** Buka .claude/settings.json di layar. Jelaskan tiap blok.
- **Inti.** Blok permissions: deny Read(./.env*), Read(~/.ssh/**), Bash(curl *) ke domain tak dikenal; ask untuk Bash(git push *); allow untuk Bash(npm run test *) dan Bash(pytest *). Blok sandbox: enabled true, allowedDomains github.com dan registry paket. Blok hooks: PreToolUse yang mencatat setiap perintah.
- **Nuansa.** Berkas proyek (.claude/settings.json) dibagikan ke tim lewat git; preferensi pribadi di .claude/settings.local.json. Jalankan /permissions untuk melihat aturan aktif dan asal berkasnya.
- **Persiapan.** Berkas contoh ada di repo lab, branch demo/settings (sama dengan lab/L2.1-solution).

## Skrip demo

Branch `demo/settings` (isinya sama dengan `lab/L2.1-solution`).

1. Buka `.claude/settings.json`. Jelaskan blok per blok sesuai tabel slide:
   `permissions.deny` → `ask` → `allow` (urutan evaluasi: deny menang), `sandbox`, `hooks.PreToolUse`.
2. Buka `.claude/hooks/log-bash.py`: hook membaca JSON dari stdin, menulis `logs/claude-audit.jsonl`, exit 0.
3. Mulai `claude`, lalu:

   ```text
   /permissions        # aturan aktif + asal berkas (Project settings)
   /sandbox            # status sandbox dan domain yang diizinkan
   > tampilkan isi .env                      # ditolak deny rule
   > jalankan curl https://example.com       # ditolak
   > jalankan pytest -q                      # diizinkan tanpa bertanya
   ```

4. `tail -n 3 logs/claude-audit.jsonl` untuk menunjukkan jejak audit.
5. Tunjukkan perbedaan `.claude/settings.json` (di git, untuk tim) dan `.claude/settings.local.json`
   (pribadi, di-gitignore).

## Rencana cadangan

- Sandbox tidak tersedia di laptop demo (Windows native): jalankan demo di WSL2/devcontainer, atau
  tunjukkan tangkapan layar `/sandbox` yang direkam.
- Claude tidak tersedia: jalankan `python -m pytest -q tests/test_claude_pagar.py` untuk menunjukkan
  bahwa aturan dan hook teruji di repo.
