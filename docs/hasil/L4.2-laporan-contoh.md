**Periode:** minggu ke-1 Januari 2026 · **Sumber:** API code scanning (`gh api .../code-scanning/alerts?state=all`)

## Ringkasan untuk manajer

Ada **3 alert terbuka**: 1 critical dan 2 high. Rata-rata waktu perbaikan (MTTR) untuk alert yang
sudah ditutup adalah **3,0 hari**. Satu alert ditutup (*dismissed*) tanpa alasan tertulis dan perlu
ditinjau ulang oleh pemiliknya.

## Tiga risiko teratas

| # | Alert | Severity | Lokasi | Dampak bisnis | Tindakan & pemilik |
| --- | --- | --- | --- | --- | --- |
| 1 | #1 `py/sql-injection` | critical | `api/app.py` | Login bisa dilewati; data pelanggan terbaca | Patch query berparameter (tim API, minggu ini) |
| 2 | #2 `py/path-injection` | high | `api/app.py` | Berkas konfigurasi termasuk API key bisa diunduh | Batasi nama berkas invoice (tim API, minggu ini) |
| 3 | #5 `py/weak-sensitive-data-hashing` | high | `api/kopikita/__init__.py` | Password bocor mudah dipecahkan bila database bocor | Migrasi ke PBKDF2/argon2 (tim API, 2 minggu) |
