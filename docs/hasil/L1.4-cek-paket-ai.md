# Verifikasi paket yang disarankan AI (contoh jawaban Lab L1.4)

Sebelum menjalankan `pip install` untuk paket yang disarankan Claude atau asisten AI lain,
periksa lima hal berikut. Isi tabel dengan data sungguhan dari registry; jangan menebak.

| Pemeriksaan | Cara | Tanda bahaya |
| --- | --- | --- |
| Paket benar-benar ada | Buka `https://pypi.org/project/<nama>/` | 404: nama hasil halusinasi, jangan dipasang |
| Umur paket | Lihat tanggal rilis pertama di tab *Release history*, atau `curl -s https://pypi.org/pypi/<nama>/json` lalu periksa kunci `releases` | Rilis pertama kurang dari 30 hari |
| Jumlah unduhan | `https://pypistats.org/packages/<nama>` | Unduhan sangat sedikit untuk fungsi yang umum |
| Maintainer | Bagian *Maintainers* di halaman PyPI dan repo sumbernya | Satu maintainer baru tanpa paket lain |
| Kesehatan repo | `https://scorecard.dev/viewer/?uri=github.com/<org>/<repo>` (OpenSSF Scorecard) | Skor rendah, tidak ada branch protection atau rilis bertanda tangan |

## Catatan peserta

| Nama paket yang disarankan | Ada di PyPI? | Rilis pertama | Unduhan/bulan | Maintainer | Keputusan |
| --- | --- | --- | --- | --- | --- |
| | | | | | Pakai / Tolak / Cari alternatif |

Aturan tim: paket yang gagal satu pemeriksaan di atas tidak boleh masuk `requirements.txt`
tanpa persetujuan reviewer keamanan.
