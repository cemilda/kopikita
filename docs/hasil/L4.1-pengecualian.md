# Uji kebijakan agen dan daftar pengecualian (contoh jawaban Lab L4.1)

## Uji: matikan sandbox lewat settings proyek

1. Pasang kebijakan di laptop uji (butuh hak admin; di organisasi nyata didistribusikan MDM
   atau server-managed settings dari Claude.ai):

   ```bash
   sudo mkdir -p /etc/claude-code
   sudo cp managed-settings.json /etc/claude-code/managed-settings.json
   ```

   macOS: `/Library/Application Support/ClaudeCode/managed-settings.json`.
   Windows: `C:\Program Files\ClaudeCode\managed-settings.json` (jalur lama `C:\ProgramData` tidak lagi
   dibaca; sandbox tetap butuh WSL2).

2. Di repo, ubah `.claude/settings.json` → `"sandbox": {"enabled": false}`, lalu mulai ulang Claude.
3. Jalankan `/sandbox` dan `/permissions`.

Hasil yang diharapkan: sandbox **tetap aktif** dan aturan deny dari managed settings tampil dengan
sumber *Managed*. Managed settings berada di puncak urutan prioritas dan tidak bisa ditimpa
settings proyek, settings lokal, maupun argumen baris perintah. `curl` ke domain di luar
`allowedDomains` organisasi tetap ditahan.

4. Kembalikan `.claude/settings.json` dan hapus berkas uji bila laptop dipakai peserta lain.

## Pengecualian yang dicatat kelompok

| Pengecualian | Alasan | Kontrol pengganti | Pemilik | Kedaluwarsa |
| --- | --- | --- | --- | --- |
| `docker` di luar sandbox (`excludedCommands`) | Docker butuh socket daemon | Hanya di laptop build; image tetap dipindai Trivy di CI | Tim platform | Ditinjau tiap kuartal |
| Pengguna Windows tanpa WSL2 | Sandbox tidak tersedia di Windows native | Wajib devcontainer atau WSL2; `failIfUnavailable: true` mencegah jalan tanpa sandbox | IT | Sampai migrasi WSL2 selesai |
| Domain registry internal | Paket internal di `pypi.kopikita.example` | Ditambahkan ke `allowedDomains` organisasi, bukan proyek | Tim keamanan | — |

Jebakan: kebijakan yang terlalu ketat (mis. tanpa registry paket sama sekali) mendorong developer
memakai alat lain di luar Claude Code yang tidak dipagari. Setiap pengecualian ditulis, punya
pemilik, dan punya tanggal tinjau.
