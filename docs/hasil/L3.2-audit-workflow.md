# Audit workflow repo lab (contoh jawaban Lab L3.2)

Branch `lab/L3.2-start` = aplikasi dasar + hasil Lab L1.2 (`codeql.yml`).

| Workflow | Izin sebelum | Action | Secret | Masalah | Sesudah (L3.2) |
| --- | --- | --- | --- | --- | --- |
| `ci.yml` | `permissions: write-all` | `checkout@v7`, `setup-python@v7` (tag) | `PAYMENT_API_KEY` di env job | Izin jauh di atas kebutuhan; secret terekspos ke semua langkah padahal tidak dipakai; tag bisa digeser | `contents: read`, secret dihapus, action dipin SHA |
| `codeql.yml` | `contents: read`, job `security-events: write` | `checkout@v7`, `codeql-action/*@v4` (tag) | — | Izin sudah minimal; hanya tag | Action dipin SHA |
| `deploy.yml` | tidak ada blok `permissions` (pakai default repo) | `checkout@v7` (tag) | `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY` statis | Default token bisa `write` (tergantung setelan repo); kredensial cloud berumur panjang | `contents: read`, action dipin SHA. **Access key statis dicatat sebagai risiko terbuka → diganti OIDC di Lab L4.3** |
| `security-digest.yml` (baru) | `contents: read`, `issues: write`, `security-events: read` | `checkout`, `claude-code-action` (SHA) | `ANTHROPIC_API_KEY` | — | Claude hanya `Read,Write`, `--max-turns 8`; issue dibuat langkah `gh`, bukan oleh agen |

## Temuan utama

- `ci.yml` memakai `write-all`: siapa pun yang bisa memicu workflow (termasuk agen CI)
  mewarisi hak tulis penuh. Menjalankan test cukup `contents: read`.
- Semua action dipin ke commit SHA penuh 40 karakter, dengan komentar versi (`# v7.0.1`)
  agar Dependabot (`github-actions`) tetap bisa mengusulkan pembaruan.
- SHA diambil dari repo resmi action, bukan fork:
  `git ls-remote --tags https://github.com/github/codeql-action 'v4.39.1*'`.
  Untuk tag beranotasi muncul dua baris; pakai SHA pada baris `^{}` (commit), bukan SHA objek tag:
  `9b3254085494b55a0f7c4c2b3d2d52cc712ce370 refs/tags/v4.39.1^{}`.
- Agen digest tidak memegang tool tulis GitHub. Data diambil dan issue dibuat oleh langkah
  deterministik; Claude hanya menyusun teks dari berkas JSON.
