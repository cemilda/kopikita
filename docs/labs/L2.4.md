## Dari slide

Teks di bawah ini sama persis dengan slide lab.

**Tujuan.** Memasang review keamanan Claude di setiap PR dan membandingkan komentarnya dengan alert CodeQL.

1. Tambahkan secret API key Claude; commit security-review.yml berizin minimal.
2. Buka PR berisi endpoint baru yang rentan XSS.
3. Baca komentar inline Claude; bandingkan dengan alert CodeQL.
4. Perbaiki, push ulang, pastikan komentar terselesaikan.

**Jebakan umum.** Memberi workflow izin contents: write atau secret deploy yang tidak dibutuhkan.

## Persiapan

- API key Claude (Console) untuk secret repo. Pemakaian menghabiskan token API dan menit Actions.
- Jadikan `lab/L2.4-start` default branch (CodeQL dari L1.2 sudah ada di branch start).

```bash
git switch lab/L2.4-start && git switch -c kerja/L2.4
```

## Langkah rinci

### Langkah 1 · Tambahkan secret API key Claude; commit security-review.yml berizin minimal.

Settings → Secrets and variables → Actions → **New repository secret**: `ANTHROPIC_API_KEY`.

Buat `.github/workflows/security-review.yml` dengan izin minimal:

```yaml
on:
  pull_request:
    types: [opened, synchronize]
permissions:
  contents: read
  pull-requests: write          # hanya untuk menulis komentar
jobs:
  security-review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
        with:
          ref: ${{ github.event.pull_request.head.sha || github.sha }}
          fetch-depth: 2
      - uses: anthropics/claude-code-security-review@0c6a49f1fa56a1d472575da86a94dbc1edb78eda # main
        with:
          comment-pr: true
          claude-api-key: ${{ secrets.ANTHROPIC_API_KEY }}
```

Action ini tidak punya tag rilis, jadi dipin ke commit SHA cabang `main` repo resminya.
Merge ke `lab/L2.4-start`.

### Langkah 2 · Buka PR berisi endpoint baru yang rentan XSS.

Buka PR berisi endpoint rentan XSS. Tulis sendiri atau pakai branch uji:

```bash
git switch -c uji/xss lab/L2.4-start
# api/greeting.py: return f"<h1>Halo, {name}!</h1>" dengan name dari request.args
```

Jalan pintas: `gh pr create --base lab/L2.4-solution --head aux/L2.4-pr-xss --title "Tambah endpoint sambutan"`
(branch `aux/L2.4-pr-xss` dibangun di atas `lab/L2.4-solution`, jadi workflow review sudah ada).

### Langkah 3 · Baca komentar inline Claude; bandingkan dengan alert CodeQL.

Tunggu check **Security Review** dan **CodeQL**. Baca komentar inline Claude (berkas, baris,
severity, penjelasan, saran) lalu isi tabel di `docs/hasil/L2.4-perbandingan.md`:
temuan mana yang ditemukan Claude, mana oleh CodeQL (`py/reflective-xss`), mana oleh keduanya.

Untuk tanya-jawab di PR (mis. "@claude jelaskan risiko baris ini"), workflow terpisah memakai
`anthropics/claude-code-action@v1`. Itu di luar cakupan lab ini.

### Langkah 4 · Perbaiki, push ulang, pastikan komentar terselesaikan.

Perbaiki di branch PR yang sama: escape nilai `name` (`markupsafe.escape`) dan batasi panjangnya.
Push ulang. Pemicu `synchronize` menjalankan review lagi. Verifikasi temuan tidak muncul lagi,
alert CodeQL berstatus Fixed di PR, lalu tandai komentar lama *Resolved*.

## Bukti selesai

- Workflow dengan `permissions` persis `contents: read` dan `pull-requests: write`, tanpa secret lain.
- PR dengan komentar inline Claude tentang XSS dan alert CodeQL.
- Tabel perbandingan terisi.
- Push perbaikan → review ulang bersih untuk XSS.

## Kunci jawaban

Berkas yang berubah dari `lab/L2.4-start` ke `lab/L2.4-solution`:

- `.github/workflows/security-review.yml`
- `docs/hasil/L2.4-perbandingan.md`

Kunci di `lab/L2.4-solution`: `.github/workflows/security-review.yml` dan
`docs/hasil/L2.4-perbandingan.md` (hasil yang diharapkan + contoh perbaikan).

Batasan yang perlu disampaikan: action review ini belum diperkuat terhadap prompt injection, jadi
pakai hanya untuk PR tepercaya. Jangan memakai `pull_request_target` untuk PR dari fork, karena
memberi akses secret ke kode yang tidak tepercaya. Di repo publik, GitHub tidak memberikan secret
ke workflow `pull_request` dari fork, sehingga review dari fork otomatis tidak berjalan.

Jebakan slide: memberi workflow `contents: write` atau secret deploy yang tidak dibutuhkan.
Review hanya perlu membaca kode dan menulis komentar.
