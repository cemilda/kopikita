## Langkah rinci

### Langkah 1 · Pasang Semgrep MCP; izinkan hanya tool security_check dan semgrep_scan.

Daftarkan server sebagai konfigurasi **proyek** (tersimpan di `.mcp.json`, dibagikan lewat git) dan
pin versinya, karena server MCP adalah kode pihak ketiga yang berjalan di luar sandbox Bash:

```bash
claude mcp add --scope project semgrep -- uvx semgrep-mcp@0.9.0
cat .mcp.json
```

Izinkan **hanya** dua tool di `.claude/settings.json` → `permissions.allow`:

```json
"mcp__semgrep__security_check",
"mcp__semgrep__semgrep_scan"
```

Tool lain dari server ini (mis. `semgrep_scan_with_custom_rule`) tetap meminta persetujuan.
Mulai ulang Claude, setujui server proyek saat diminta, cek `/mcp` → `semgrep` *connected*.

### Langkah 2 · Minta Claude membangun endpoint pencarian produk dengan loop scan sampai bersih.

```text
> Tambahkan endpoint GET /search?q=<teks> di blueprint baru api/search.py yang mencari produk
  berdasarkan nama. Setelah menulis kode, jalankan security_check pada berkas yang diubah,
  perbaiki setiap temuan, dan ulangi sampai bersih. Tulis test di tests/test_search.py,
  termasuk input berbahaya (kutip tunggal, %, <script>). Jalankan pytest -q.
```

Amati loop-nya: tulis → `security_check` → perbaiki → ulang. Versi akhir yang diharapkan:
`LIKE ?` dengan parameter `f"%{q}%"`, nilai `q` yang dipantulkan di-escape, dan blueprint
didaftarkan di `api/app.py`.

### Langkah 3 · Tambahkan aturan di CLAUDE.md: jalankan security_check sebelum menyatakan selesai.

Tambahkan aturan di `CLAUDE.md`:

```markdown
## Aturan khusus Lab L2.3b

Sebelum menyatakan sebuah fitur selesai, jalankan `security_check` (Semgrep MCP) pada berkas yang
diubah dan perbaiki temuannya sampai bersih. "Scan bersih" bukan jaminan aman; tetap baca kodenya
dan jalankan `pytest -q`.
```

Uji: mulai sesi baru, minta perubahan kecil di `api/search.py`, dan pastikan Claude menjalankan
`security_check` sendiri tanpa diminta.

### Langkah 4 · Buka PR; bandingkan hasil MCP dengan CodeQL dan Semgrep (rule L1.2b) di CI.

```bash

```

Di PR, bandingkan tiga sumber: hasil `security_check` terakhir di terminal, check **CodeQL**, dan
check **Semgrep (rule kustom)** dari L1.2b. Catat di deskripsi PR apa yang ditemukan siapa.

- Transkrip singkat loop: minimal satu putaran temuan → perbaikan → scan bersih.
- `pytest -q` lulus termasuk `tests/test_search.py`.
- PR dengan perbandingan MCP vs CodeQL vs Semgrep CI.
