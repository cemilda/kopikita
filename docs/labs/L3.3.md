## Langkah rinci

### Langkah 1 · docker build; trivy image; catat jumlah CVE per severity.

```bash
docker build -t kopikita:rentan .
mkdir -p docs/hasil && trivy image kopikita:rentan | tee docs/hasil/L3.3-sebelum.txt
trivy image --format json -o sebelum.json kopikita:rentan
python - <<'PY'
import json, collections
c = collections.Counter(v["Severity"] for r in json.load(open("sebelum.json"))["Results"]
                        for v in r.get("Vulnerabilities") or [])
print(dict(c))
PY
```

Catat jumlah CVE per severity. Perhatikan juga: image berjalan sebagai root, menyalin seluruh repo
(termasuk `.env` lokal!), dan menjalankan server pengembangan Flask dengan debugger.

### Langkah 2 · Minta Claude menerapkan pola Dockerfile.secure dari repo referensi.

```text
> Terapkan pola docs/reference/Dockerfile.secure ke Dockerfile repo ini: base image slim dengan
  tag versi spesifik, multi-stage (dependensi dipasang di stage build), hanya salin api/,
  pengguna non-root uid 10001, gunicorn wsgi:app, HEALTHCHECK ke /health, database di /tmp.
  Jangan jalankan docker; saya yang menjalankannya.
```

Tambahkan juga `.dockerignore` bila belum ada (`.env`, `.git`, `.venv`, `logs/`, `*.db`).
Di `docker-compose.yml`: `read_only: true`, `tmpfs: [/tmp]`, `KOPIKITA_DB=/tmp/kopikita.db`.

Jebakan slide: Docker tidak berjalan di dalam sandbox Claude. Jalankan `docker` sendiri, atau tambahkan
`docker` ke `sandbox.excludedCommands` dengan sadar bahwa perintah itu berjalan tanpa sandbox.

### Langkah 3 · Build, scan ulang, bandingkan angka; pastikan aplikasi masih jalan.

```bash
docker build -t kopikita:keras .
trivy image --format json -o sesudah.json kopikita:keras
docker compose up -d --build && sleep 3 && curl -s localhost:5000/health   # {"status":"ok"}
docker compose exec api id                                                 # uid=10001(app)
docker compose down
```

Bandingkan angka sebelum dan sesudah. Pastikan aplikasi masih menjawab `/health` dan login berhasil.

### Langkah 4 · Tambahkan job CI: trivy → SARIF → upload ke code scanning.

Tambahkan `.github/workflows/image-scan.yml`: build image (`docker/build-push-action`, `load: true`),
`aquasecurity/trivy-action` dengan `format: sarif` dan `severity: HIGH,CRITICAL`, lalu
`github/codeql-action/upload-sarif` kategori `trivy-image`. Izin job: `contents: read`,
`security-events: write`. Semua action dipin SHA (pola L3.2).

## Bukti selesai

- Tabel CVE per severity sebelum dan sesudah (dari JSON Trivy, bukan perkiraan).
- `curl /health` → `{"status":"ok"}` dan `id` → uid 10001 dari kontainer yang dikeraskan.
- Workflow **Image scan** hijau; tab Security memuat alert kategori `trivy-image`.
