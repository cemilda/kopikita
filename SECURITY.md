# Kebijakan Keamanan KopiKita

Struktur berkas ini mengikuti contoh Modul 02 repo paulasilvatech/Secure-Code-AI-Dev.

## Supported Versions

| Versi | Didukung |
| --- | --- |
| `main` | Ya |
| Rilis lain | Tidak |

## Reporting a Vulnerability

Jangan melaporkan kerentanan lewat issue publik. Gunakan
**Security → Report a vulnerability** (private vulnerability reporting) di repo ini,
atau kirim email ke tim keamanan kelas yang ditunjuk instruktur.

Sertakan: endpoint atau berkas yang terdampak, langkah reproduksi, dan dampak yang Anda lihat.

## Response Timeline

| Tahap | Target |
| --- | --- |
| Konfirmasi laporan diterima | 2 hari kerja |
| Triase dan penilaian severity | 5 hari kerja |
| Perbaikan severity Critical/High | 14 hari |
| Perbaikan severity Medium/Low | 30 hari |

## Catatan

Repo ini adalah aplikasi latihan yang **sengaja rentan**. Laporan dari peserta kelas diperlakukan
sebagai latihan alur pelaporan.
